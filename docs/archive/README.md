# Архив документации Mise

[Карта актуальных документов](../../README.md#документация).

Активные документы содержат только действующие правила и открытые gates. Датированные отчёты удалены из рабочего дерева, но сохранены в Git на базовом срезе `de36592`; они не являются текущим release verdict или backlog.

Исходник можно прочитать без восстановления файла:

```bash
git show de36592:<имя-файла>
```

## Как использовать старый отчёт

Сначала воспроизвести наблюдение на текущем exact HEAD. Затем классифицировать его как `fixed`, `open release gate`, `accepted/deferred` или `obsolete` и записать только актуальный итог в канонический документ. Старый номер P0/P1 сам по себе не разрешает правку и не доказывает дефект текущего релиза.

Без нового разрешения владельца не менять четыре исключённые области из UX-аудита: спорные фото блюд, оценку готовки около 620 минут, cooking CTA на «Неделе» и визуальное различие невыбранных «Аллергия / Не люблю».
