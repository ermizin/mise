# Mise

Mise — веб-приложение для милпрепа: оно превращает цели по КБЖУ в меню, список покупок и подписанные порции на несколько дней. Продуктовые границы зафиксированы в [`PRODUCT.md`](PRODUCT.md), текущий план — в [`ROADMAP.md`](ROADMAP.md), правила рецептурного контура — в [`RECIPE_HANDOFF.md`](RECIPE_HANDOFF.md).

## Локальный запуск

Требуются Node.js `>=22.13.0` и `pnpm`.

```bash
pnpm install --frozen-lockfile
pnpm dev
```

Приложение откроется на `http://localhost:3000`. Перед запуском `predev` автоматически создаёт локальную D1 и применяет миграции через `wrangler.local.json`. Проверить состояние базы отдельно:

```bash
pnpm db:local:check
```

Если в существующей локальной базе есть таблицы без истории миграций, скрипт остановится и предложит новый путь `MISE_D1_PERSIST_TO`; данные молча не перезаписываются.

## Проверка изменений

```bash
pnpm run lint
pnpm test
```

`pnpm test` пересобирает детерминированный runtime-каталог рецептов, выполняет production build и запускает весь набор Node-тестов. Изменение источников рецептов, overlay или canonical mapping должно включать обновлённые generated-артефакты и проверку по [`RECIPE_HANDOFF.md`](RECIPE_HANDOFF.md).

## Структура

- `app/` — интерфейс и API;
- `domain/` — расчёты питания и Recipe Engine;
- `data/` — исходные, редакционные и generated-данные рецептов;
- `db/` и `migrations/` — схема и миграции D1;
- `scripts/` — импорт, аудиты, генерация каталога и упаковка релиза;
- `tests/` — продуктовые и технические регрессии.

Карта удалённых датированных отчётов и их замена: [`docs/archive/README.md`](docs/archive/README.md).

## Production

Публичный Mise работает на `https://mise.ermizinm.ru` через VPS. Публикация разрешена только по явному запросу владельца и выполняется из точного проверенного коммита по правилам [`AGENTS.md`](AGENTS.md). Sites не является production-таргетом Mise.
